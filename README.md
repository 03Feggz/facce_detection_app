# Streamlit Face Detection App
face detection app prototype
A user-friendly Streamlit application that leverages OpenCV's Viola-Jones (Haar Cascade) algorithm to detect faces in uploaded images.

Features include:

Uploading an image for face detection.

Adjusting detection settings such as scaleFactor and minNeighbors.

Customizing the rectangle color around the detected faces.

Saving and downloading the modified image with face annotations.
